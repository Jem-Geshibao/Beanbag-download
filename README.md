# 豆包无水印下载助手

> 一键获取豆包 AI 生成图片的无水印原图，并支持单张/批量下载（ZIP 打包）。

---

## 🚀 简介

**豆包无水印下载助手**（版本：v1.1.0）是一个面向 Chromium 浏览器的扩展，自动在 doubao.com 页面捕获生成图片的原始无水印地址，提供“下载无水印原图”按钮并支持批量下载与 ZIP 打包。

## ✨ 主要功能

- 自动检测页面中 AI 生成的图片并提取原图 URL
- 在图片预览处显示“下载无水印原图”按钮（单张下载）
- 在扩展面板查看已捕获图片、选择后批量下载并生成 ZIP（基于 JSZip）
- 隐私友好：不上传用户数据、不与第三方服务器通信，仅在 doubao.com 运行

## 📦 安装（开发 / 本地测试）

1. 打开 Chrome/Edge，访问 `chrome://extensions/`。
2. 打开右上角 **开发者模式**。
3. 点击 **加载已解压的扩展程序（Load unpacked）**，选择本仓库根目录 `Beanbag-downloadv1.0`。
4. 在 `doubao.com` 生成图片后，打开扩展按钮或点击“豆包图片管理”面板进行下载。

> 如果你修改了源码，加载后请在扩展页面点击“刷新”或重新加载已解压的扩展。

## 🧭 使用说明

- 打开 `https://*.doubao.com/*`，在生成或查看图片时，插件会自动拦截页面请求并尝试提取原图地址。
- 在图片预览（或缩略图）处会出现“下载无水印原图”按钮，点击即可下载单张图片。
- 打开扩展面板（点击扩展图标 -> 打开），会列出已捕获的图片，勾选后点击“批量下载”生成 ZIP。

## 🔐 权限说明

插件会请求以下权限：

- `downloads`：用于保存图片和 ZIP
- `tabs`：用于在标签页间查询与通讯
- `scripting`：用于注入拦截脚本到页面

此外，host 权限允许访问：
```
*://*.doubao.com/*
*://*.byteimg.com/*
```

## 🧩 关键文件说明

- `manifest.json` - 扩展元信息与权限
- `js/content.js` - 页面注入脚本：拦截请求并注入下载按钮
- `js/background.js` - 后台脚本：处理下载、与标签通信
- `js/options.js` - 面板脚本：展示图片列表、打包下载
- `html/options.html` / `html/about.html` - 面板与关于页
- `js/jszip.min.js` - 用于生成 ZIP 的第三方库

## ⚠️ 已知限制与排查建议

- 插件仅在 `doubao.com` 域下工作；确保已在正确页面生成图片。
- 若未检测到图片，检查浏览器控制台（右键 → 检查 → Console）是否有脚本错误。
- 批量下载功能依赖跨域资源可被 fetch 成功获取（CORS 限制可能导致部分图片无法加入 ZIP）。
