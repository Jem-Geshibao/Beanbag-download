# Doubao No-Watermark Download Helper

> One-click extraction of original/no-watermark images generated by Doubao AI, with single and batch download (ZIP packaging) support.

---

## 🚀 Overview

**Doubao No-Watermark Download Helper** (version: v1.1.0) is a Chromium extension that automatically captures original image URLs from doubao.com, shows a "Download Original" button in the preview, and supports batch downloading with ZIP packaging.

## ✨ Key Features

- Automatically detects AI-generated images on the page and extracts original image URLs
- Adds a "Download Original (no watermark)" button on image preview for single-image downloads
- Provides an extension panel that lists captured images, supports selection and batch download (ZIP via JSZip)
- Privacy friendly: does not upload user data and runs only on doubao.com

## 📦 Installation (Developer / Local Testing)

1. Open Chrome/Edge and go to `chrome://extensions/`.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select this repository folder `Beanbag-downloadv1.0`.
4. Generate images on `doubao.com`, then open the extension popup or the image manager to download.

> If you modify the source, reload the unpacked extension in the extensions page.

## 🧭 Usage

- Visit `https://*.doubao.com/*`. The extension intercepts page requests and attempts to extract original image URLs.
- A "Download Original (no watermark)" button appears on the image preview or thumbnail—click to download a single image.
- Open the extension panel to see captured images, select items and click "Batch Download" to create a ZIP file.

## 🔐 Permissions

The extension requests these permissions:

- `downloads` — to save images and ZIP files
- `tabs` — to query and communicate with tabs
- `scripting` — to inject the interceptor script into pages

Host permissions:
```
*://*.doubao.com/*
*://*.byteimg.com/*
```

## 🧩 Important Files

- `manifest.json` — extension metadata and permissions
- `js/content.js` — page-injected script: intercepts requests and injects the download button
- `js/background.js` — background script: handles download actions and tab communication
- `js/options.js` — popup/panel script: displays image list and handles batch downloads
- `html/options.html` / `html/about.html` — panel and about pages
- `js/jszip.min.js` — JSZip library used for packaging ZIP files

## ⚠️ Known Limitations & Troubleshooting

- The extension only runs under the `doubao.com` domain; ensure you are on the correct page.
- If no images are detected, check the browser console (Right-click → Inspect → Console) for script errors.
- Batch download relies on fetch to retrieve images; CORS restrictions may prevent some images from being added to the ZIP.
